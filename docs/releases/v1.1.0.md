# NGS-Agent v1.1.0

Cleanup release. The repository now ships a single product: the no-LLM NGS
results interpreter. No new features, no rule or threshold changes.

## What changed

- **One product in the repo.** The entire legacy pre-v1 tree — the old
  LLM-based analysis package, its container agents, the orchestration
  layer, the pipeline submission CLI, worker, and demo files — is removed.
  What remains is `core/` (parsers, rules, receipts) and `doors/` (the
  `ngs` CLI and the Box), plus fixtures, examples, and docs.
- **Packaging surface cleaned up.** One console script: `ngs`. The
  legacy-only script alias, the LLM/TUI extras, and their
  dependencies are gone; `pyproject.toml` is the single source of truth
  (no `requirements.txt`). The wheel ships `core/` and `doors/` only.
- **CI green on the maintained tree.** Ruff, mypy, and pylint now run
  against `core/`, `doors/`, `tests/`, and `scripts/` — all passing —
  and the full suite is 339 tests with the receipts audit reporting
  `0 findings without a valid receipt`.
- **Threshold honesty (labels only).** The README gained a "Thresholds"
  section and both rule modules a matching comment: duplication
  20/50/70%, freemix 3/5%, alignment 75/50%, and assignment 30% are
  defaults pending expert sign-off; labs should tune per assay type.
  No value changed.
- **Docs made consistent.** `CLI_USER_GUIDE.md` rewritten for the
  `ngs <file>` surface; `NOTES.md` records the resolved decisions as
  DECIDED and carries corrected test counts; `docs/PUBLISHING.md` follows
  the current release flow; the stale bug report was triaged item by item
  and removed; the v1.0.0 and v0.2.0 release notes on GitHub were
  corrected (VCF interpretation is permanently out of scope; v0.2.0 is
  the superseded legacy CLI).

## Install — unchanged

```bash
pipx install "ngs-agent[box] @ git+https://github.com/ranaalyan1/NGS-Agent.git"
ngs sample_fastqc.zip

# or from a clone
git clone https://github.com/ranaalyan1/NGS-Agent.git && cd NGS-Agent
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/python -m doors.cli fixtures/fastqc/sample_fastqc.zip
```

Conda and Docker recipes are unchanged (`environment-box.yml`,
`docker build -t ngs-agent .`). Same command shape as v1.0.0: `ngs <file>`.
No LLM, no network calls in the assessment code, a receipt on every
finding, and `UNKNOWN` remains a valid verdict — never a guess.
