## 2026-09-26 — Stations 9–13

Station 9 adds a read-only Nextflow log watcher (`--watch`, default 15 seconds)
that judges only newline-terminated evidence and leaves normal one-shot output as
the final card. Station 10 adds single-sample VCF call-quality QC only (depth,
missingness, neutral/extreme Ti/Tv, het/hom and FILTER); gVCF, multi-sample and
unsupported records stay honest unknowns. Station 11 adds eight ranked
Snakemake signatures. Station 12 adds five Cromwell signatures; WDL source stays
recognised, not statically analysed. Station 13 is the optional nf-core recipe;
its process uses the published image with a read-only root filesystem and does
not fail on findings unless explicitly configured. No core network calls or
pipeline execution were added.

The combined station regression file currently has 12 test functions (including
per-signature loops); the receipt audit covers every generated Finding and
prints `0 findings without a valid receipt` when green. All newly added fixtures
are generated by `scripts/make_fixtures.py`.

## Refused, on the Forbidden List

These were not built, and should not be built without a scope change:

* **Pipeline execution** — no Nextflow/Snakemake/Docker/Slurm launching.
  NGS-Agent reads the outputs of runs; it never starts one.
* **Swarm / autonomous / self-directed execution** — nothing here decides what
  to do next on its own. The pipeline is fixed: sniff, parse, rules, answer.
* **VCF variant prioritisation** — call-quality metrics are now judged, but a VCF
  never gets pathogenicity, gene context, or an ACMG classification.
* **Debate personas / multi-LLM discussion** — v1 has no language model at
  all. Every sentence is a template plus a number.
* **MCP server** — no tool-calling protocol surface.
* **Accounts, auth, cloud upload, user databases** — no network code exists in
  `core/`; the tests grep for it.

## Not built, because no station asked for it

Recorded here instead of being quietly added:

1. **`ngs --out DIR`** to write the HTML report from the CLI. The Box has
   "Download report"; the CLI has `--json`. The HTML writer is one call away
   (`core.report.write_report`) if wanted.
2. **CRAM support.** The sniffer detects `BAM\x01`; a CRAM would come back
   `unknown`. The audit's truncation check reads the BGZF EOF marker, which is
   BAM-specific.
3. **Beyond 2,000 files / 4 MB text files.** `parse_folder` caps both
   (`MAX_FILES`, `MAX_TEXT_BYTES`) and silently skips the rest. A real WGS run
   folder with thousands of sharded BAMs is not handled yet.
4. **More charts in the report.** Only the per-base quality curve is drawn
   (inline SVG). Adapter and GC curves are numbers in "Details".
5. **Cohort-aware thresholds.** `AUD-DUP-04` compares samples inside one folder
   only. It says nothing when a folder holds a single sample, which is honest
   but incomplete.
6. **Localisation.** English only.

## Decisions a human should review

* **DECIDED 2026-09-28 — `ngs` stays with the v1 door.** The console script
  points at `doors.cli:main`. The legacy-only script alias was removed with
  the legacy tree, so every install gets the v1 command surface
  (`ngs <file>`). The old assignment lives in git history.
* **DECIDED 2026-09-28 — the legacy tree is removed.** The pre-v1
  implementation (the old LLM-based package, its container agents, the
  orchestration layer, the submission CLI, and the worker) was deleted in
  the v1.1.0 cleanup instead of shipping beside the product; it remains
  reachable only through git history. The Forbidden-List section below now
  describes the product itself, which never had those parts.
* **`README.md` was rewritten** for the new product. The old README is in git
  history.
* **Signature `reference` URLs** point at tool homepages and documentation
  roots only. If you want deep links into specific manual sections, they need
  checking one by one — a wrong reference is worse than a short one.
* **Thresholds** are consolidated at the top of `core/rules/qc_rules.py` and
  `core/rules/audit_rules.py`. They encode opinions (duplication 20/50/70%,
  freemix 3/5%, alignment 75/50%, assignment 30%) that a biologist should
  sign off on — labelled as defaults in the README's Thresholds section.

was planted where in `scripts/make_fixtures.py`.
